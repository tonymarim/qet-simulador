qet-simulador

Escolha um arquivo .qet acima ou arraste-o para cá.
Tudo roda no seu navegador: nada é enviado para a internet.

Dica: no Chrome ou no Edge, use Instalar (ícone na barra de endereço) para ter o simulador como aplicativo, sem internet, e abrir arquivos .qet pelo botão direito > Abrir com.

Como usar

Clique e segure uma botoeira para pressioná-la. Shift+clique mantém pressionada. Clique no disjuntor para ligar/desligar, no relé térmico para simular sobrecarga, na parada de emergência para travar/destravar e no sensor para colocar/tirar a peça.
